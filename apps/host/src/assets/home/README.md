# Home picture

Drop one image here named `home-hero` — `.webp`, `.avif`, `.png` or `.jpg`
(for example `home-hero.webp`). With more than one, that order wins. Home shows it above the brand; with none
here it shows the maiscope logo (`assets/brand/logo.svg`) instead. It is drawn inside a box 280px
tall (less on short screens), whole and never stretched. The file ships with
the app, so keep it small (a few hundred KB).
