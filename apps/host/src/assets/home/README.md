# Home picture

Drop one image here named `home-hero` — `.webp`, `.avif`, `.png` or `.jpg`
(for example `home-hero.webp`). Home shows it above the brand; with none
here it shows the maiscope logo (`assets/brand/logo.svg`) instead. Square or portrait reads best;
it is drawn at most 280px tall and never stretched. The file ships with
the app, so keep it small (a few hundred KB).
